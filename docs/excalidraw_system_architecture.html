⚡ 2. Online Conversational LangGraph Engine

STATISTICALLY PARALLEL

End-to-end multi-turn stateful pipeline with session checkpoints (InMemorySaver & Vercel parity):

1

1️⃣ contextualize_query Node

LLM REWRITER
Conversational Memory Rewriter
Inspects last 6 turns of chat history. Resolves pronouns & elliptical references ("tell me all", "what about both?") into standalone, explicit banking queries.
state["standalone_query"] = rewritten
⬇️ Passes Standalone Query
2

2️⃣ route_intent Node

CLASSIFIER
Intent & Entity Classifier
Categorizes into: DISCOVERY (multi-product lists), FACT (single named entity specs), COMPARISON (2+ products), or FALLBACK (chitchat/out of scope).
Schema: IntentClassificationOutput (Pydantic)
⬇️ Intent-Aware Branching
3

3️⃣ retrieve_context Node

HYBRID RETRIEVER
Multi-Strategy Hybrid Search (RRF)
• DISCOVERY: limit=25, filtered by category, deduplicated to max 1-2 chunks per unique product_name.
• FACT: limit=6, strict product entity pinning and cross-card chunk isolation.
• COMPARISON: bilateral partitioned sub-queries (limit=4 each) merged cleanly.
Score: Reciprocal Rank Fusion (RRF)
⬇️ Context Quality Gate
4

4️⃣ grade_documents Node

GUARD GATE
Grounding & Relevance Grader
Evaluates retrieved chunks against standalone_query. If RRF score < 0.35 or context is empty, routes directly to safe banking fallback without hallucinations.
⬇️ Validated Context
5

5️⃣ generate_response Node

SYNTHESIZER
Intent-Specialized Synthesis (Gemini 2.5 Flash)
• DISCOVERY: High-level category summary + clean Markdown catalog table (Cards | Fees | Salary | Perks).
• FACT: Structured specification card strictly grounded in verified facts.
• COMPARISON: Side-by-side head-to-head comparison matrix.
⬇️ Metadata Injection
6

6️⃣ build_citations Node

DETERMINISTIC
Server-Constructed Ground Truth Citations
Assembles verified Emirates NBD source URLs, KFS download links, and retrieval similarity scores. LLM is never allowed to hallucinate links.

🛡️ 5-Tier Defensive Guardrails

SECURITY
Tier 1: Prompt Injection Firewall
Regex + Semantic checks blocking jailbreak patterns, instruction overrides, and prompt dumps.
Tier 2: RRF Threshold Gate
Rejects low-confidence queries (score < 0.35) before reaching the generator node.
Tier 3: Pydantic Schema Gate
Rigid enum validation ensuring queries are bounded to supported Emirates NBD product lines.
Tier 4: Numerical Fact Guard
Regex verification ensuring AED currency figures match retrieved source chunks exactly.
Tier 5: Server Citation Gate
Zero hallucinated URLs. Citations strictly injected from verified Qdrant payload metadata.
